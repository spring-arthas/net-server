# 账号同步好友置顶

## 目标

在 Android 好友列表中增加长按置顶/取消置顶能力，并由后端按当前登录账号持久化，保证刷新、重新登录和其他设备重新拉取好友列表后仍保持一致排序。

## 已确认规则

- 支持多个置顶好友，最近置顶排在最前。
- 置顶只影响当前用户自己的 `user_friends` 方向记录。
- 好友列表排序依次为：置顶、置顶时间、未读、在线、显示名、好友 ID。
- Android 使用乐观更新；失败只回滚目标好友；同一好友请求期间禁止重复操作。
- 不支持拖拽排序，也不增加多设备实时推送。

## 交付边界

- 后端 migration、协议帧、好友关系服务、好友列表字段与排序。
- Android 协议、API、状态更新、长按底部弹层和图钉展示。
- 自动化测试、Java 8 后端 JAR、Android Debug APK。
- 不启动后端、不启动模拟器、不安装 APK、不创建 Git commit。
