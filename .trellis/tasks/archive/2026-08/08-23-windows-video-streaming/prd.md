# Windows 客户端视频在线播放

## 背景

`net-server` 已为 macOS、iOS、Android 客户端提供视频在线播放能力。本任务将现有协议接入
WinForms `chat-service` 客户端，保持服务端多端兼容。

## 需求

1. 视频文件详情中展示图标形式的在线播放按钮，非视频文件不展示。
2. 播放器支持拖动进度条，并按目标位置重新获取视频流。
3. 播放器支持播放/暂停、停止和全屏切换。
4. 优先复用现有媒体预览协议；仅在确认兼容性缺口时调整服务端。

## 验收标准

- 常见视频扩展名能够从文件详情打开播放器。
- 首次播放和 Seek 均使用服务端媒体预览链路，且不会破坏下载/断点续传功能。
- 暂停不会丢失当前位置；停止会释放播放与网络资源；全屏可进入并退出。
- `chat-service` 与 `net-server` 均能成功构建，服务端现有测试通过。
- 非法文件、非视频文件、断线与无效范围有明确错误反馈并正确清理资源。
